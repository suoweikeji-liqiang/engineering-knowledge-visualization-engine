# Roadmap

## M0：MVP

- Story JSON。
- 两角色、8 动作、7 表情。
- 8 个科普图解。
- espeak 配音、程序化音效、字幕和 MP4。
- 第一条 HVAC 科普样片。

## M1：生产工具

- 自然中文 TTS 与音频驱动时长。
- Web 分镜预览与 JSON 编辑器。
- SVG/PNG 角色包、场景包、动作包。
- 横屏/竖屏自适应布局。
- 批量渲染、缓存、失败续跑。

## M2：AI 导演

- 资料输入、事实引用和脚本生成。
- 分镜生成、连续性检查和节奏自动修订。
- 栏目模板：沙雕对话、硬核科普、事故复盘、产品解释。

## M3：评测闭环

- 事实准确率、字幕可读性、音画同步、镜头重复度。
- 观众留存反馈回流。
- 组件、模板和策略版本化优化。
