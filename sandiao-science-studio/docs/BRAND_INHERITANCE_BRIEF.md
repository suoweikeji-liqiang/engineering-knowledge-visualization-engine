# 小行星AI观测站品牌继承简报

## 结论

工程科普动画不应建立一个与“小行星AI观测站”无关的新品牌，也不应把 AI 日报模板直接动画化。正确策略是：**继承母品牌识别和价值观，重新设计适合角色表演与工程图解的栏目视觉语言。**

建议品牌架构：

```text
小行星AI观测站
└── 小行星原理剧场（工作名）
    └── 对话式工程科普
```

“沙雕”描述喜剧节奏，不进入主品牌锁定；否则会限制以后制作硬核科普、事故复盘、产品解释和企业培训内容。

## 已有品牌事实

### 名称与定位

- 品牌名：小行星AI观测站。
- 账号定位：像在小型太空观测站里追踪 AI 模型、产品和开发生态变化的中文科技账号。
- 现有口号：用证据追踪AI变化。
- 现有表达气质：冷静、明确、少废话。
- 现有视觉主题：dark tech / observatory telemetry。

### 稳定符号

- 小行星与倾斜轨道环。
- 观测站、望远镜、雷达屏、星图轨道线。
- 遥测刻度、观察编号、信号状态和证据标签。
- “发现一个信号 → 展开观察 → 验证结论”的叙事隐喻。

最终颜色由设计系统统一，但必须保持“夜色观测 + 明亮信号 + 可阅读纸面”的关系，不能退化成普通蓝色科技模板。

## 动画栏目的继承方式

### 强继承

- 正式频道名、轨道标记、品牌核心色。
- 片头 1–2 秒识别、角标、章节转场和片尾。
- 观察/验证语义：放大镜、扫描、锁定、证据确认、结论落章。
- 对事实边界和技术准确性的重视。

### 弱继承

- 雷达网格、遥测线和星点只作为局部 motion motif。
- 深色控制室只用于“进入观察模式”，不作为所有背景。
- 证据 chip 用在事实核验和结论镜头，不覆盖普通人物对话。

### 重新设计

- 栏目标识与中英文副标题。
- 原创角色或品牌观察员。
- 日常、实验室、机房和抽象图解场景。
- 角色动作、表情、嘴型和喜剧节奏。
- 适合 16:9 与 9:16 的动画构图。

## 角色与 mascot 的决策题

母品牌目前只有 mascot prompt，没有成熟、稳定的角色资产。反重力需比较两种方案：

1. 将一位主角重构为“小行星观察员”，另一位作为普通观众/工程师。
2. 保留双主角，把品牌观察员作为片头、转场和结论中的轻量第三角色。

推荐优先方案 1，避免常规镜头同时出现三个人物。无论选择哪一种，必须保证品牌角色不是只贴一个太空头盔的普通卡通人，而有稳定轮廓、道具、动作习惯和观察员职责。

## 栏目命名建议

首选工作名：`小行星原理剧场`。

理由：

- “小行星”承接母品牌。
- “原理”覆盖 HVAC、控制、机械、软件和 AI，不限制领域。
- “剧场”允许人物对话、冲突和动作表演，不像传统网课。

备选：

- 小行星工程实验室：工程感强，但内容领域稍窄。
- 小行星科普剧场：直白，但差异化较弱。
- 小行星观察课：品牌一致，但表演感不足。

建议栏目口号：`把复杂原理画明白`。母品牌口号“用证据追踪AI变化”继续用于账号级场景，不强行放进每条工程动画。

## 品牌露出节奏

- 片头：1–2 秒，轨道锁定一个“本期观察目标”。
- 常驻角标：只保留简化轨道 mark 或短栏目名，不占用标题区。
- 章节转场：扫描/锁定/展开图层，不使用无意义炫光。
- 结论：从“观察中”切换为“已验证/结论”，形成栏目固定仪式。
- 片尾：母品牌全称 + 栏目名，可带下一观察目标。

品牌识别应靠重复的结构和动作建立，而不是在每个镜头写满“小行星AI观测站”。

## 验收问题

评审反重力方案时必须回答：

1. 静音、去掉频道文字后，是否仍能感到“观测站/发现信号”的品牌逻辑？
2. 是否能看出它属于小行星AI观测站，又不是日报卡片模板？
3. 母品牌元素是否帮助叙事，而不是抢占人物与图解空间？
4. 非 AI 主题是否仍然自然，不会显得贴错频道包装？
5. 栏目是否具有可连续制作 50 期以上的资产扩展能力？
