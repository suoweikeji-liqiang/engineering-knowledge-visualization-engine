- `xiaolan-desk.jpg`: host / opening home base
- `xiaolan-surprised.jpg`: reaction / narrative turn
- `xiaolan-pointing.jpg`: explainer / closing synthesis

`ai_daily_brief_factory_v3`. The renderer deliberately uses the character only
at chapter boundaries; technical diagrams remain the primary explanatory layer.
