# Metaphor assets

`xiaolan-agent-loop.png` is an original generated scene based on the user-owned
Xiaolan character reference. It turns the agent loop into a physical sequence
of paper stepping stones inside the Asteroid AI Observatory.

Identity anchors retained across the character system:

- long black hair with galaxy-purple highlights;
- gold Saturn hair clip;
- round gold glasses;
- cream clothing and warm observatory light.

The image contains no labels. Semantic step names remain renderer-owned so the
same asset can be reused with different languages and lesson variants.
